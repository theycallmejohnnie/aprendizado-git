# 🧮 Calculadora em Python (com Tratamento de Exceções)

Projeto prático desenvolvido para exercitar conceitos fundamentais de Python, como tratamento de erros com `try/except`, funções, expressões `lambda` e `list comprehension`.

## 🚀 Funcionalidades

- Operações básicas: Soma, Subtração, Multiplicação e Divisão.
- Validação de entrada para garantir apenas números inteiros (`try/except`).
- Tratamento de divisão por zero.
- Menu de opções gerado dinamicamente com *list comprehension*.
- Opção de reiniciar a calculadora ou sair do programa.

## 🛠️ Tecnologias e Conceitos Utilizados

- **Python 3**
- Estruturas de repetição (`while True`, `break`, `continue`)
- Tratamento de exceções (`try / except ValueError`)
- List Comprehension e `enumerate()`
- Funções Lambda

## ▶️ Como executar

No terminal, execute:

```bash
python3 main.py
```
